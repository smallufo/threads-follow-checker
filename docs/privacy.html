Privacy Policy

Threads Follow Checker — Last updated: 2026-03-26

Overview

Threads Follow Checker is a browser extension that helps you see which accounts you follow on Threads also follow you back. We are committed to protecting your privacy.

Data Collection

We do not collect, transmit, or store any personal data on external servers.

All data processed by this extension stays entirely on your local device.

What Data Is Stored Locally

The extension stores the following data in your browser's local storage (chrome.storage.local):

  • A list of usernames and display names from your Following list
  • A list of usernames and display names from your Followers list

This data is used solely to generate the follow-back comparison report. You can clear all stored data at any time using the "Clear Data" button in the extension popup.

Permissions Used

  • activeTab — To read the follower/following list from the currently active Threads page. Only activated when you explicitly click a scan button.
  • storage — To save scan results locally so you don't have to re-scan every time.
  • Host permission (threads.com / threads.net) — The content script runs only on Threads pages to enable auto-scrolling and username collection.

Third-Party Services

This extension does not use any third-party analytics, tracking, or advertising services. No data is sent to any external server.

Changes to This Policy

If we make changes to this privacy policy, we will update this page with the new date. Continued use of the extension after changes constitutes acceptance of the updated policy.

Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.

隱私權政策

Threads Follow Checker — 最後更新：2026-03-26

概述

Threads Follow Checker 是一個瀏覽器擴充功能，幫助您查看在 Threads 上追蹤的帳號是否也有追蹤您。我們致力於保護您的隱私。

資料收集

我們不會收集、傳輸或將任何個人資料儲存在外部伺服器上。

本擴充功能處理的所有資料都完全保留在您的本地裝置上。

本地儲存的資料

本擴充功能使用瀏覽器的本地儲存空間（chrome.storage.local）儲存以下資料：

  • 您的追蹤名單中的用戶名和顯示名稱
  • 您的粉絲名單中的用戶名和顯示名稱

這些資料僅用於產生追蹤回追比對報告。您可以隨時透過擴充功能彈出視窗中的「清除資料」按鈕刪除所有已儲存的資料。

使用的權限

  • activeTab — 用於讀取目前 Threads 頁面上的追蹤/粉絲列表。僅在您主動點擊掃描按鈕時啟用。
  • storage — 用於在本地儲存掃描結果，以便您不必每次都重新掃描。
  • 網站權限（threads.com / threads.net） — 內容腳本僅在 Threads 頁面上運行，以實現自動滾動和用戶名收集。

第三方服務

本擴充功能不使用任何第三方分析、追蹤或廣告服務。不會將任何資料傳送到任何外部伺服器。

政策變更

如果我們對本隱私權政策進行變更，我們將更新此頁面及日期。在變更後繼續使用本擴充功能即表示接受更新後的政策。

聯絡方式

如果您對本隱私權政策有任何疑問，請在我們的 GitHub 儲存庫提出 issue。
