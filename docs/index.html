Chrome Extension

Threads Follow Checker

Find out which accounts you follow on Threads don't follow you back.

Features

  • Auto-scrolls your Following and Followers lists on Threads
  • Compares both lists and generates a follow-back report
  • Shows display names alongside usernames
  • Filter by "follows back" or "not following back"
  • Search by username or display name
  • Export report as CSV
  • Supports English and Traditional Chinese
  • All data stays local — nothing is sent to any server

How to Use

  1. Install the extension and go to your profile on threads.com
  2. Open your Following list, click the extension icon, and hit Scan Following
  3. Switch to your Followers list and hit Scan Followers
  4. Click Generate Report to see the full comparison in a new tab
